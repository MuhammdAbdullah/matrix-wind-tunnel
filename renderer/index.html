Velocity Lookup Table

With the fan stopped, click Zero Sensor. Then click Start capture to run the fan at 10%, wait for the pressure to settle and type it in the Pressure box. Press Enter: the pressure is converted to air speed with V = √(2·|ΔP| / ρ) (ρ = 1.20 kg/m³, CP0704 Worksheet 1) and the fan moves on to the next 10%. Enter after 100% stops the fan. You can click any Fan % to jump to it, or type a velocity directly. Nothing is sent to the controller until you press Save Table.

Connect over the network

No USB cable? Read the IP address on the controller's touchscreen (Settings page), type it here and press Connect. USB always takes priority.

Only the Wind Tunnel app is accepted. The controller drops any other program that tries to connect and may then change its address, so check the touchscreen again if the connection stops working.

Communication Settings

The PID is pre-filled with 0xA1, the default in Process Control V2's bootloader screen (the application itself is 0xF010). It has not been confirmed on a Wind Tunnel controller: if no device with that PID appears but exactly one other USB HID device with this VID does, Connect uses it and fills in its PID. Otherwise check the PID in Windows Device Manager while the controller is in bootloader mode.
